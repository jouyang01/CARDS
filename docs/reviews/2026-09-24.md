## Dev Notes → backlog

### 1. [MED — engine + data, Dev Note #2] Aegis's Grounding Strike → Warding Wall

*"Change Aegis's Grounding Strike to be a prep phase, 4 cool down skill named Warding Wall which puts
down a 4 tile long wall that lasts until the end of this turn that does 25 damage to those who walk
through it and weakens them for the next turn."* This **replaces** a Blast (line, dmg 14 + slow) with a
Prep **line-hazard** — a genuinely new mechanic (a *wall* of hazard tiles), so per golden rule #2 it
gets a generic implementation. **Fix: backlog WARDING-WALL (engine + data, ENGINE ASK)** — place a
**trap on every tile of a line/wall shape** (generalising TRAP-CENTRE's single placement), each carrying
`onTrigger: [damage 25, weaken duration 2]`, with a lifetime covering only the placement turn; a
**hazard, not a blocker** (units walk through it — no pathing/LoS change); trap triggers already fire on
dash/move entry and exclude the owner's team. Prep cd 4 as directed. **Design confirmations owed to the
Designer** (aim direction, dasher-through, kit-reshape intent) — flagged. Ruled PROPOSED (WARDING-WALL).

### 2. [LOW — data + client, Dev Note #3] Bastion's Ram Charge → all-in-line

*"Bastion's Ram Charge should be a linear aoe dash that affects all players in a line, not just the
first enemy hit; the preview should be like a line attack that also shows the ending dash location."*
The engine already supports it via `chargeHits: "all"` (validated, read at `resolve.ts:1347`). **Fix:
backlog BASTION-RAM-LINE (data + client)** — `chargeHits: "all"` on `bastion.ram_charge` (hits every
enemy the path crosses, damage 15 + knockback 1 each); the client draws the charge as a **line** over
the crossed tiles **plus a landing marker**. Ram Charge stays a dash → CD-BAND-DASH sets its cd to 4
(composes). Ruled (BASTION-RAM-LINE); also resolves session-7 OQ #3 for this ability.

### 3. [INFO — Dev Note #1] The cooldown bands are already in the spec

*"Review PR #95 which affects character skill cooldowns and ensure it gets added into the spec."* PR #95
routed the owner's cooldown directive into **CD-BAND-DASH / CD-BAND-BLAST / CD-BAND-INVARIANT** (with
the 2026-09-23 evidence review) — **already scheduled and kept.** **One reconciliation:** WARDING-WALL
replaces `aegis.grounding_strike`, so **CD-BAND-BLAST drops it** from its retune list (it is no longer a
Blast). Sequence WARDING-WALL before CD-BAND-BLAST.

### 4. [MED — server, session-7 OQ #1] A downed seat shouldn't make everyone wait the full window

DEATH-HANG's downed seat holds (correct), but the room waits the full 40s on a turn it cannot act in.
**Fix: backlog DOWN-SEAT-SKIP (server)** — `#answering()` excludes a seat with no living controllable
units, so the turn resolves as soon as everyone who *can* act has (the "no turn ever waits on a player"
principle, applied to a downed seat). Ruled (DOWN-SEAT-SKIP).
