## Dev Note routed

### [HIGH — client render, owner "IMPORTANT"] Camera panning + centre on the character

*"IMPORTANT: Need to add Camera panning and the auto camera center should be on the character, not the
board."* Two gaps, both confirmed in the code:
- **No pan gesture exists.** `renderer3d.ts` has orbit (drag → rotate, `ORBIT_SENSITIVITY`) and wheel-zoom;
  a search for pan/translate/right- or middle-button turns up nothing. The player cannot translate the view
  — which matters more since BOARD_ZOOM lets the board run off the viewport edges.
- **The auto-camera centres on the wrong thing.** `fitCamera` (`app.ts:710`) is
  `focusOn(ownUnits().map(u => u.pos), 1)` — the centroid of **all** the seat's units, which for a 2v2 sits
  *between* the two characters; `selectUnit` (`app.ts:1218`) does **not** recentre on the selected
  character; and `fitBoard()` (`app.ts:2605`) still centres on the **map middle** in some states. So the
  frame reads as "the board", exactly as the owner says.

**Fix: backlog CAMERA-CONTROLS (client).** Add a player **pan** gesture (translate, clamped to
board+margin, folded into the same auto-vs-manual model orbit already uses), and make the planning
auto-centre target the **active/selected character** — recentre on `selectUnit`, `focusOn([unit.pos], 1)`
— not the all-units centroid or the board. This is a pure view change (no engine/rules impact) — see the
item for the determinism guard.
