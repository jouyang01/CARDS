## Verification

- `npm test` → **1876 passing** (858 + 792 + 226 across the workspaces). `npm run typecheck` clean;
  purity/determinism grep clean. **Engine source untouched this batch** (`git diff 6c7c626 HEAD --
  packages/engine/src` is empty) — the whole batch is client + server, so phase order and dash
  immunity are unchanged by construction; the pure engine never learns of the clock.
- **M3-TIMER** — the decision clock is **injected** (`RoomHub` takes `now: () => number`; the DO
  passes `Date.now`, tests pass a counter — no sleeping tests, and the engine stays clock-free). One
  deadline per turn for the whole room (a simultaneous turn cannot resolve at four different moments);
  a Time Bank charge is per-seat but the ten seconds are everybody's, **added** to what remains;
  **missed → hold** needed no new code (`mergeSeatOrders` already contributes nothing for an
  un-submitted seat, and a unit with no orders holds); the window crosses the wire as a **duration**,
  not an absolute instant, so a fast browser clock cannot mis-draw it. Sound.
- **M3-RECONNECT** — a match disconnect **holds** the seat (a lobby disconnect deletes it — `leave`
  owns the split); a seat that locked in **before** dropping keeps its submission; a disconnected
  un-submitted seat **stops counting toward the lock total** (the room does not wait out the full
  clock for an empty chair); reclaim is a **socket→seat binding** (`#bound`), resync is `matchStarted`
  carrying the seat. The **partial-team handoff is DERIVED** — `controlledUnits` computes the loan
  from `connected` + `missedTurns` (stand-in = first connected seat on the team in join order), so
  reclaiming un-does it with no hand-back step, no window where two or zero seats own a character.
  Deterministic and N-safe. **Promoted the standing lean to a ruling in edge-cases at the Builder's
  request (Decision 15).**
- **M3-END-SCREEN / WAYPOINT-DASH-CLEAR** — `outcomeFor(state, viewer)` renders the engine's own
  `status`/`winner` as a point of view (a networked seat sees "you won", not "Team 2", which it can't
  interpret); `liveWaypointMarks(marks, movePath)` keeps only marks still on the live route, so a mark
  **can never outlive the path it annotates** (the class of bug, not the instance).

## Done well (one line)

Both new stateful rules are made **underivable-when-wrong**: the disconnect handoff is computed from
`connected`+`missedTurns` rather than by moving `unitIds` (so reclaim has no hand-back step to get
wrong), and waypoint marks are filtered to the live path (so a mark can't survive its route) — two
"there is no bad state to reach" designs rather than two more places to remember to clean up.

## Issues, ranked

No defects. The items below are Open-Question rulings and follow-ups.

### 1. [MED — server, deployed-play robustness] The timer window does not survive DO hibernation (OQ #1, #3)

`#deadline` and the Time Bank charge counts are **in memory only**; a Durable Object evicted
mid-decision returns with no open window (the turn waits for players, not the clock, until the alarm
re-arms) and with everyone's charges reset. **No regression** vs pre-M3-TIMER, and it self-heals next
frame — but eviction happens in **production**, rarely locally, so this is a real gap the moment the
game is deployed. **Fix: backlog TIMER-PERSIST** — persist the deadline + charges on the `Room` record,
rehydrate in `#arm`. Ruled in edge-cases. Small; **land it with or before M3-DEPLOY.**

### 2. [LOW — client] The presence/handoff facts are shipped but silent (OQ #4, #5)

A stand-in's board grows the disconnected teammate's characters with nothing saying "you are covering
for Bo" (#4), and `RoomView.seats` carries `connected` that no screen draws (#5) — same gap (data
present, display absent), same small item. **Fix: backlog NET-PRESENCE-UI** — mark disconnected seats
in the lobby/topbar; tell a covering seat it is covering. Ruled in edge-cases. Client-only.

### 3. [INFO — ruled / flagged] Idle-player, rematch (OQ #2, #6)

- **OQ #2 (connected-idle):** ruled — `missedTurns` counts disconnection, not slowness, by design; a
  connected seat that never acts is timed out to **hold** each turn (M3-TIMER prevents a hang) and
  simply plays badly. An idle-kick/forfeit is a **post-v1** nicety, flagged, not scheduled.
- **OQ #6 (rematch):** confirmed deferred — re-entering the same room needs a protocol conversation
  (both agreeing to re-arm) that isn't specced; the loop closes via the create form. **M3-REMATCH**
  flagged future, not scheduled.
