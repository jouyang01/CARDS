## Issues, ranked

### 1. [MED — engine gap, Builder-surfaced] The Dash phase applies no debuffs (OQ #3)

`runDash` applies damage and displacement but **no status effects**, so **Bramble Stride's Root and
Tempest Run's Slow reach nobody** — two shipped kits doing less than they say. **Fix: backlog
DASH-STATUS (engine)** — Dash-phase abilities apply their status riders to victims (as Blast does),
inside PHASE-STATUS-FIRST's status sub-step. Not a batch-3 item, but a real gap the batch exposed.

### 2. [MED — client, Dev Note #1+#3] Damage previews ignore centre/axis differentials

*Dev Note #1: "Damage previews need to account for things like the center of Cinder's Ember bolt and
center of Bastion punch. Audit all skills to ensure damage preview is correct."* Cinder's Ember Bolt
has an inner core (22 centre / 14 ring) and Bastion's Crushing Slam an axis bonus (+8 line), but the
preview does not surface the differential. *Dev Note #3: "Aegis's auto attack does not have anything
special about it. Make sure it shows in both description and gameplay."* — the description already
reads "a 3-wide wall of force" (`shield_bash` desc updated), so the gap is the **preview/gameplay**:
the `beamWidth: 3` lane must render as a 3-wide constant lane, not a plain cone. **Fix: backlog
PREVIEW-AUDIT (client)** — audit **every** ability's damage preview against its actual resolution
(inner/ring, axisBonus, beamWidth, DoT, heal-vs-damage tiles) and fix the mismatches; Aegis's beam and
the Cinder/Bastion centres are named cases.

### 3. [MED — bug, Dev Note #2] Kestrel's Spread mode resolves/renders as a line, not a cone

*"Kestrel's auto attack is not working as a cone at all, it's just a line. It should be like Elle's
auto attack from Atlas Reactor."* The data is correct — Twin Bolts `modes: [Focus line 6, Spread cone
2]` (Elle's wide-short cone ↔ thin-long line). So the **Spread (cone) mode is not activating** — the
client either never offers/applies the toggle or previews mode 0 regardless. **Fix: backlog
KESTREL-CONE (client bug)** — the Spread mode must resolve **and** preview as `cone` range 2; **drive
the real mode toggle in the test**, not just `abilityProfile` (the waypoint/chase lesson — the pure
function is fine; the wiring is where these hide).

### 4. [LOW — client, Dev Note #4] The lobby wants a persistent skill-detail panel

*"When selecting a character in the lobby, the mouseover is going great, but it should also expand into
a bigger window on the side that shows a description of all the skills. There is space on the left."*
LOBBY-INSPECT shipped the hover tooltip; the owner wants **more** — a persistent side panel (left,
where there's space) listing **all** of the selected character's skills with descriptions. **Fix:
backlog LOBBY-DETAIL-PANEL (client)** — a persistent left-side panel for the selected/hovered
character's full kit; reuse the ability tooltip/description content.

### 5. [LOW — data, Dev Note #5] Ablative Field shields 35, should be 40

*"Ablative shielding should shield for 40."* `ablative_field` (Ablative Field) currently shields **35**.
**Fix: backlog ABLATIVE-40 (data)** — `amount: 35 → 40` and update the description ("Shield 35" →
"Shield 40"). Owner directive; ships as a one-line data edit.
