## Dev Notes → the one remaining lever

Both Dev Notes are about **when a trap goes off**, and PR #97 already laid every rail. Mapping them onto
the shipped behaviour:

| Arrival | Dev Note wants | Mine (default) today | Wall today |
|---|---|---|---|
| Move / dash onto or through | trigger | ✅ | ✅ |
| **Knocked through / onto** | **trigger** | **❌ (no `displacement`)** | ✅ |
| Blink **onto** the tile | trigger | ✅ (`teleport` in default) | ❌ (authored "goes around") |
| Blink **past** the tile | no trigger | ✅ none | ✅ none |

The single mismatch is the knock-through row for an **ordinary mine**: `DEFAULT_TRAP_ENTRIES` is
`['move','dash','teleport']`. Dev Note #1 (*"Traps should trigger if an enemy is knocked through"*) is a
statement about **traps**, not walls, so the fix is to add `'displacement'` to the default — pulling the
exact lever my 2026-08-14 ruling named ("the first lever to pull if shove-into-trap combos are wanted
later"). Dev Note #2 (*"not if the enemy blinks PAST"*) is **already satisfied** and needs no code — a
teleport occupies only its landing square, so a blink past a trap was never an entry.

### [MED — engine, Dev Notes #1 + #2] TRAP-SHOVE-DEFAULT

**Add `'displacement'` to `DEFAULT_TRAP_ENTRIES`**, so every ordinary mine (Vex Overwatch Trap, Thorn
Barbed Sling + Snare Bloom) catches a knock-through, and lock the blink-past behaviour with a test.
Ruled in edge-cases (**TRAP-TRIGGER**, superseding the 2026-08-14 knockback-exclusion). This is the only
engine change; **it reverses a v1 ruling, so it ships with the test flip in the same commit** — full AC
+ Spec Notes in BACKLOG.

**One flag, not a blocker:** the wall keeps its authored *"a blink goes around it"* exception (owner
session-8 Dev Note: *"hit dashes, moves, and displacements, but not blinks"*), so a blink that lands on
a wall tile does **not** fire it, while a blink onto a **mine** does. That is the one place the new
general rule and the wall's authored exception diverge; kept as the owner last wrote it, flagged so they
can say if the wall should now bite a blink that lands on it.
