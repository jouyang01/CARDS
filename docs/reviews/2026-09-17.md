## The designer's 21-note batch → scheduled (see BACKLOG)

Everything in `dev-notes-batch-3.md` is now a backlog item, in the designer's suggested order (bugs →
CASTER-SAFE/RECOIL → PHASE-STATUS-FIRST → traps → ALLY-SAFE → BRUSH-BREAK → client/server). The
Analyzer notes worth flagging to the Builder:

1. **PHASE-STATUS-FIRST (#21) is the deepest and highest-risk item — its tests are the deliverable.**
   Each phase splits into two **simultaneous** sub-steps: all statuses apply, then all damage/heal
   computes against post-status state. **Simultaneity must survive** — both teams' statuses land
   together, then both teams' damage batches against a pre-damage HP snapshot, so **mutual Weakens both
   blunt and mutual kills still land in full**. This supersedes "a Blast-Weaken does nothing until next
   turn" and will flip existing tests — they update with it (golden rule #3). Ships with the
   mutual-Weaken symmetry test and the mutual-kills regression the designer named. **Determinism:** both
   sub-steps are order-independent batches — keep them so.
2. **CASTER-SAFE (#16+18) changes shipped behavior** (Ravok self-hits today, verified live) — a global
   "a unit is never a target of its own harmful effects," with **RECOIL (#17, `selfDamagePct`)** as the
   opt-in exception (Seismic Rupture 50%, bypasses cover, consumes shields). One rule, two data edits.
3. **BRUSH-BREAK (#19) touches the vision/reveal seam** — being hit in brush applies **no Reveal**;
   instead a unit-scoped `brushBroken` marker (duration 2) suppresses that unit's brush concealment.
   Must compose with REVEAL-FIX/CAMO-REVEAL (Reveal stays the piercing status; Stealth stays
   damage-broken) — the Builder reconciles, and it is the one item that edits `canSee` + the fog render.
4. **TIMER-PERSIST client bug (#5)** is a *different* thing from the shipped server TIMER-PERSIST — the
   lock-in timer must render **every** Decision phase, not only turn 1. Renamed **TIMER-EVERY-PHASE** to
   avoid the name collision.
5. **RESOLVE-PARTIAL (#8)** is largely already true (M3-TIMER's missed→hold is per-character) — it needs
   a confirming test and any gap closed, not a rebuild.
