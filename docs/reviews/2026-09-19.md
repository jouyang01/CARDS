## Issues, ranked

### 1. [MED — client bug, Dev Note #2] No Ready button; Start is un-clickable

*"There is no 'ready' button. Both Seat 0 and seat 1 have a 'start game' but it cannot be clicked."*
The lobby code is correct in isolation (creator → "Start match" gated on `canStart`; others → "Ready
up" → `client.ready`). The symptom means **`isCreator` is true for both seats**. **Leading root cause:**
the reconnect ticket is in **`window.localStorage`** keyed by room code (`main.ts:144`) and every
connect joins with it (`main.ts:167`); two **tabs of the same browser share localStorage**, so a second
tab reclaims the first tab's (creator's) seat — both become the creator, neither shows Ready, and Start
stays disabled because no distinct second seat readies. **Fix: backlog LOBBY-READY-FIX (client)** —
scope the ticket per browsing context (sessionStorage / non-colliding key) and refuse a reclaim of a
still-**connected** seat (a fresh client joins a new seat, never steals a live one). Also fix the
seat-row `is-ready` marker, which reads `lobby.ready` (= *picked* seats) instead of `readied`
(`lobby.ts:210`). **Root-cause by driving two real net clients** (ties to HARNESS-BROADEN). Ruled
PROPOSED (RECLAIM-SCOPE) in edge-cases.

### 2. [LOW — client, Dev Note #1] Catalyst tooltips are slow

*"Catalyst descriptions on mouseover appear very slowly, can we speed up how soon they show up?"* The
catalyst buttons use the native HTML `title` attribute (`lobby-screen.ts:275`), whose ~0.5–1s reveal
delay the browser owns and the page cannot shorten. **Fix: backlog CATALYST-TIP-FAST (client)** —
replace the native `title` with an **immediate custom tooltip** on `mouseenter` (reuse the LOBBY-INSPECT
hover-panel mechanism, which already fires instantly), so the catalyst description shows without the
browser delay.

### 3. [MED — test insurance, OQ #6] Broaden the controller harness

`app-harness.ts` can drive the whole controller but is exercised only by KESTREL-CONE. The ready-button
bug (issue 1) is *exactly* the wiring class it would catch. **Fix: backlog HARNESS-BROADEN (client
test)** — extend it across aiming, catalysts, free actions, chase, playback **and the lobby ready
flow**; make LOBBY-READY-FIX's regression live here (two net clients).
